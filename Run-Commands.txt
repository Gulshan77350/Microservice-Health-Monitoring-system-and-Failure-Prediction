=======================================================
Microservice Health Monitoring System — Execution Guide
=======================================================

Option 1: Complete Stack via Docker Compose (Recommended)
--------------------------------------------------------
Start all 6 services (Payment, Order, Notification, Prediction API, Collector DB, Dashboard UI):

$ docker-compose up --build -d

Access Points:
- Dashboard UI:      http://localhost:5173
- Prediction API:    http://localhost:8004/docs
- Collector API:     http://localhost:8005/docs
- Payment Service:   http://localhost:8001/metrics
- Order Service:     http://localhost:8002/metrics
- Notification Svc:  http://localhost:8003/metrics


Option 2: Native Development Mode (Terminal Split)
--------------------------------------------------
Terminal 1 — Core Microservices & ML API:
$ docker-compose up --build payment-service order-service notification-service prediction-api

Terminal 2 — Metrics Collector & SQLite:
$ cd collector
$ pip install -r requirements.txt
$ python collector.py

Terminal 3 — React Dashboard:
$ cd dashboard
$ npm install
$ npm run dev
